# 第一轮上电检查清单

- [ ] 不装轮或将车体稳定架空，电源限流可用。
- [ ] 检查 VBAT、3.3 V、GND 和 TB6612 VM，无短路后再插电。
- [ ] ST-Link 可连接，PA13/PA14 没有被关闭。
- [ ] 上电后 OLED 显示 `DISARM` 或明确的 `IMU FAULT`，电机无输出。
- [ ] 断开 MPU 或遮断 I2C，确认状态为 `IMU FAULT` 且电机保持关闭。
- [ ] IMU 初始化成功后，车体在稳定姿态保持约 0.5 秒，确认才会自动进入平衡控制。
- [ ] 逐一低 PWM 检查 M1(A) 与 M2(B)，不串扰。
- [ ] 手动转动两轮，确认编码器符号符合前进定义。
- [ ] 前后倾斜，确认 Pitch 与电机补偿方向正确。
- [ ] 停止蓝牙命令超过 300 ms，确认目标速度平滑回零而非突然反向。
- [ ] 模拟大角度倾倒，确认进入 `FALLEN` 且不会自动重新授权。
- [ ] 测量 PA4 ADC 与电池电压，确认分压和 VDDA 后才启用低压阈值。

完成所有项目之前，不得车轮落地运行或提高 PWM 限幅。
