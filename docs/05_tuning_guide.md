# 安全调参指南

禁止在未验证方向时让车轮落地，也禁止直接开放 CascadeV1 的较高 PWM。

1. 车轮悬空，确认 IMU 初始化完成后，姿态稳定约 0.5 秒才自动进入平衡控制。
2. 单独给 M1、M2 小输出，确认每路只影响对应 TB6612 A/B 通道。
3. 手转车轮，确认两侧 `counts/s` 的前进符号一致；只改 `board_config.h` 的编码器符号。
4. 缓慢前后倾，确认 Pitch、gyro Y 和电机补偿方向相反；错误时只改集中方向配置。
5. 校准 `balance_angle_deg`，轮子仍悬空。
6. 只开角度 PD，以 SafeBringup 的低 PWM 限幅开始；先调 Kp，再调 Kd。
7. 低速调速度 PI：先 Kp，再小步增加 Ki，观察积分不会在饱和时累积。
8. 调 yaw rate，再逐步提高 PWM 限幅。每一步都验证遥控超时、倾倒和 IMU 断开保护。

参数、轮径、PPR、减速比、IMU 朝向均未完成实车确认。任何一次改动后都要重新回到悬空验证。
